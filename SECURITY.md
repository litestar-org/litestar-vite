# Security Policy

## Supported Versions

The following versions of Litestar Vite currently receive security updates:

| Version | Supported |
| --- | --- |
| `0.33.x` | Yes |
| `< 0.33` | No |

## Reporting a Vulnerability

Please do not open public GitHub issues for suspected security vulnerabilities.

Instead, report potential vulnerabilities privately through one of these channels:

- **GitHub Security Advisories**: Open a private report at <https://github.com/litestar-org/litestar-vite/security/advisories/new>.
- **Email**: Send details to [hello@litestar.dev](mailto:hello@litestar.dev).

Include a clear description of the affected component, steps to reproduce, and any relevant Python, Node.js, Vite, or framework configuration details so maintainers can reproduce and assess the report promptly.
