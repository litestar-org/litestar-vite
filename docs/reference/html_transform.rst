===================
HTML Transformation
===================

HTML transformation utilities for injecting scripts, metadata, and attributes
into HTML documents.

Common use cases:
- Inject CSRF tokens
- Inject Inertia.js page props
- Add data attributes to elements
- Inject Vite dev-server scripts for HMR
- Rewrite asset URLs for a configured asset prefix
