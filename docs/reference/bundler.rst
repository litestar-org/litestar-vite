========================
PyApp Bundler & Packaging
========================

The ``litestar_vite.bundler`` module stages ``python-build-standalone``
distributions and compiles single-file PyApp executables. It backs the
``litestar assets bundle`` command described in :doc:`/usage/bundling`.
