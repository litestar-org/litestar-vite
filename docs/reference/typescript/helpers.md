# Runtime & Inertia Helpers

Browser and SSR runtime utilities for CSRF token injection, route matching, HTMX JSON templates, WebSocket/SSE event streams, Litestar Channels, Litestar Queues, Inertia page resolution, pagination helpers, and Laravel Precognition validation.
